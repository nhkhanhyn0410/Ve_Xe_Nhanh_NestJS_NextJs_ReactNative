# Mobile app

Expo mobile app cho monorepo `Ve_Xe_Nhanh_Ts`.

## Stack

- Expo SDK 55
- React Native 0.83
- Expo Router
- TanStack React Query
- Zustand
- expo-secure-store
- `@ve_xe_nhanh_ts/api-client`
- `@ve_xe_nhanh_ts/shared-types`

## Chay app

```bash
npm install
npm run dev:mobile
```

Dat API URL:

```bash
EXPO_PUBLIC_API_URL=http://10.0.2.2:3000
```

Neu chay tren thiet bi that, thay `10.0.2.2` bang IP LAN cua may backend.
